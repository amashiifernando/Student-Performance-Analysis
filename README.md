# Student Performance Analysis: G.C.E A/L Exam 2020 (Sri Lanka)

## Project Overview
This project provides a comprehensive analysis of the 2020 G.C.E. Advanced Level examination records in Sri Lanka. It uses statistical modeling and machine learning to identify factors influencing student Z-scores and academic achievement.

## Objectives
* Analyze performance across various academic streams.
* Evaluate the impact of demographic factors (age, gender) on Z-scores.
* Identify significant predictors for university entrance eligibility.
* Develop predictive models (e.g., Ridge Regression) to forecast student Z-scores.

## Methodology
1. **Data Preprocessing:** Cleaned the dataset by handling missing values and ensuring data quality.
2. **Exploratory Data Analysis (EDA):** Visualized performance distributions, gender differences and subject-wise success.
3. **Statistical Analysis:** Employed ANOVA, t-tests and Chi-square tests to determine significant relationships between variables.
4. **Machine Learning:** Built and compared multiple models, with Ridge Regression providing high predictive accuracy.
